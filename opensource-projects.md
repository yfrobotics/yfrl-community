# 云飞实验室开源项目汇总 (GitHub)

本页面汇总了云飞实验室及实验室成员(包括我本人)在GitHub上开源的项目。这其中包括系统设计、软硬件设计、开源工具、知识分享等。这其中有已经完结的项目，也有目前仍在活跃更新中的项目（随着时间推移，相信数量还会不断增加）。希望感兴趣的朋友们关注与参与。

我觉得开源是技术推进的一个重要组成部分。我自己多年以来也在坚持学习和实践开源，虽然感到开源设计中包含硬件极大提高了门槛，但是通过使用标准化设备及开源硬件可以大大提高可重复性。今后如果有机会，我会好好聊聊我对于硬件开源及机器人开源的一些想法，以及和软件开源相比存在哪些机遇和挑战。

（最后更新于：2026年02月18日）


## 社区与知识分享

- [yfrl.org](https://github.com/yfrobotics/yfrl.org): 云飞机器人实验室主页
- [community](https://github.com/yfrobotics/community): 云飞机器人实验室社区 — 在这里查看社区新闻、投稿文章、交流项目、提供改进及意见。
- [robowiki-cn](https://github.com/yfrobotics/robowiki-cn): 机器人中文维基百科 — 公共参与编辑的机器人知识库: 涵盖机器人理论、设计、算法、编程、建模、仿真等内容。
- [self-driving-handbook-cn](https://github.com/yfrobotics/self-driving-handbook-cn): 自动驾驶技术指南（中文） – 介绍自动驾驶的起源、技术以及行业应用。
- [awesome-robotics-ee-opensource](https://github.com/automaticdai/awesome-robotics-ee-opensource): 机器人/电子/机器学习中文开源项目列表 (by 云飞机器人实验室)


## 机器人与机器视觉

- [rpi-object-detection](https://github.com/automaticdai/rpi-object-detection): Object detection and tracking in real-time using Raspberry Pi and OpenCV!
- [jetson-object-detection](https://github.com/automaticdai/jetson-object-detection): Real-time object detection and tracking with Jetson and Pytorch!
- [MRWS_MultiRobot_Warehouse_Scheduling](https://github.com/automaticdai/MRWS_MultiRobot_Warehouse_Scheduling): MRWS: MultiRobot Warehouse Scheduling Framework
- [yfips-indoor-positioning-system](https://github.com/automaticdai/yfips-indoor-positioning-system): Use low-cost sensors for (multi-)robot indoor positioning and navigation.
- [guinea-pig-monitor](https://github.com/automaticdai/guinea-pig-monitor): A real-time guinea pig behavior monitoring system that uses YOLO object detection, ByteTrack multi-object tracking, optical flow analysis, and rule-based behavior classification.
- [LCS-filter](https://github.com/automaticdai/LCS-filter): Line-Circle-Square (LCS): A Multilayered Geometric Filter for Edge-Based Detection
- [a-star-maze-processing](https://github.com/automaticdai/a-star-maze-processing): Solving a maze using A* path planning. Programmed with Processing.
- [ga-optimized-nn-processing](https://github.com/automaticdai/ga-optimized-nn-processing): Demonstration of Genetic algorithm (GA) optimized Neural Network (NN) for 2D position control using Processing (a graphic library).
- [processing-laser-tracking-opencv](https://github.com/automaticdai/processing-laser-tracking-opencv): Tracking the pointing postion of a laser using Processing and OpenCV.
- [esp32-ultrasonic-with-calibration](https://github.com/automaticdai/esp32-ultrasonic-with-calibration): Use ESP32 and an ultrasonic sensor to measure distance. The result is calibrated using a termpature sensor (HTU21d) and displayed on a OLED screen.
- [arduino-ym4-robot-lib](https://github.com/automaticdai/arduino-ym4-robot-lib): The Arduino Library for the YM4 Mobile Robot platform.


## 电子设计

- [rpi-timelapse](https://github.com/automaticdai/rpi-timelapse): Timelapse shooting with Raspberry Pi and PiCam/webcam.
- [rpi-mini-dslr-camera](https://github.com/automaticdai/rpi-mini-dslr-camera): Mini DSLR camera using Raspberry Pi and the high quality camera.
- [i2cdriver-music-player](https://github.com/automaticdai/i2cdriver-music-player): Play simply music using buzzers and the I2CDriver by ExCamera.
- [arduino-yaoji](https://github.com/automaticdai/arduino-yaoji): Yaoji is an open-source digital plant based on Arduino and Android.


## IoT项目

- [yf-smart-home-iot](https://github.com/automaticdai/yf-smart-home-iot): IoT system for home sensing and home automation.
- [rpi-environmental-sensing](https://github.com/automaticdai/rpi-environmental-sensing): An open-source domestic environment sensing system build with Raspberry Pi Zero W + HTU21D + AM2306 + PMS7003. Supports report to MySQL and MQTT broker.
- [esp32-iot-htu21d-mqtt](https://github.com/automaticdai/esp32-iot-htu21d-mqtt): A low-power environmental sensing device using ESP32 + HTU21D. Supports MQTT and an OLED display.
- [blynk-http-python-lib](https://github.com/automaticdai/blynk-http-python-lib): A python library for exchanging data with Blynk using RESTful APIs.
